Model Summary

ConvNeXt-Tiny is a pure convolutional architecture that modernizes the ResNet design using techniques from vision transformers — including larger kernel sizes (7×7), GELU activations, LayerNorm, and fewer activation functions. The model achieves competitive performance with ViT-based architectures while maintaining the simplicity and efficiency of CNNs.

The classifier head has been replaced with a single linear layer mapping 768 features to 4 output classes, fine-tuned end-to-end on the OCT2017 training split.

Grad-CAM Explainability

Gradient-weighted Class Activation Mapping (Grad-CAM) produces visual explanations by computing the gradient of the predicted class score with respect to the feature maps of model.features[-1] (the last convolutional block).

The resulting heatmap is overlaid on the original OCT scan to highlight regions that contributed most to the model's prediction. For NORMAL predictions, the heatmap is intentionally suppressed to avoid showing misleading pathological focus.
